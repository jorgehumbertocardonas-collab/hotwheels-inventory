# 🏁 Hot Wheels Inventory

Catálogo interactivo de tu colección de Hot Wheels / carros a escala.

## 📱 Características

- ✅ **1,650 vehículos** disponibles
- 📸 Carga y gestiona fotos
- ⭐ Marca tus favoritos
- 🔍 Filtros avanzados (color, marca, búsqueda)
- 📊 Estadísticas en tiempo real
- 💾 Exporta tu colección (JSON/CSV)
- 📴 Funciona 100% offline
- 🏃 Muy rápido y responsivo

## 🚀 Cómo usar

### 🌐 Online (Desde cualquier celular)
Abre este link en Chrome:
```
https://tu-username.github.io/hotwheels-inventory
```

### 📱 Como App en Android
1. Abre el link en Chrome
2. Presiona el menú ⋮ (arriba derecha)
3. Selecciona **"Instalar app"**
4. Confirma
5. ¡Listo! Aparece un icono 🏁 en tu pantalla de inicio

## 📝 Datos Incluidos

- **Total de vehículos:** 1,650
- **Marcas:** 24 (Matchbox, Hot Wheels, Majorette, etc.)
- **Colores:** 46 opciones
- **Distritos:** 5 (Sorento, Riverside, Circasia, Paqueta, Cúcuta)
- **Tipologías:** 24 tipos de vehículos
- **Años:** 1190 a 2022

## ✨ Features

### Galería
- 🔍 Buscar por nombre
- 🎨 Filtrar por color
- 🏷️ Filtrar por marca
- ⭐ Ver solo favoritos
- 📷 Miniaturas con/sin foto

### Detalle del Vehículo
- 📸 Carga y visualiza fotos
- 🗑️ Elimina fotos
- ⭐ Marca como favorito
- 📋 Ver todos los datos
- 💾 Almacenamiento local

### Estadísticas
- 📊 Total de vehículos
- 📸 Vehículos con foto
- ⭐ Vehículos favoritos
- 📥 Descargar datos (JSON/CSV)

## 🔧 Tecnología

- HTML5 + JavaScript vanilla
- PWA (Progressive Web App)
- Responsive design (mobile-first)
- localStorage para almacenamiento
- Sin dependencias externas
- <400 KB total

## 📄 Almacenamiento

- **Fotos:** Se guardan en tu dispositivo (smartphone)
- **Favoritos:** Se guardan localmente
- **Notas:** Se guardan localmente
- **Datos personales:** NO se envían a internet
- **Sincronización:** Cada dispositivo es independiente

## ⚙️ Configuración

No requiere configuración. Solo abre y usa.

- Todos los datos se guardan automáticamente
- Funciona offline después de la primera carga
- Los datos persisten entre reinicios
